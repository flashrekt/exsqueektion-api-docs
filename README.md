## Updating

Edit `INTEGRATIONS_API_HANDOFF.md` and, when the contract changes, `integrations-v1.schema.json`. Push to `main`; GitHub Pages rebuilds the public documentation automatically. `index.md` includes the handoff file, so the page and downloadable Markdown share one source.

Keep API credentials out of this repository. Consumers obtain their API key separately from the service operator.
